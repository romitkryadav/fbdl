What Is a Facebook DP?

"DP" stands for Display Picture — a widely used term for a social media profile photo, particularly popular across South Asia and the broader internet. On Facebook, the DP is the circular or square photo shown at the top of every profile and Page. It appears in search results, comment sections, messenger conversations, and news feed posts. Because it is so visible, many users want to save or reference someone's DP at full size — which is exactly what this tool enables for publicly accessible profiles.

Why Can't I See the Full Profile Picture on Facebook?

Facebook crops profile pictures to a circle in the interface and only displays a small preview when you click on them. The platform does this intentionally — full-size photos are stored on their servers but the interface is designed to present a constrained view. FBviddl accesses the public image data associated with the profile URL to retrieve the original full-resolution version that Facebook stores for public profiles.
